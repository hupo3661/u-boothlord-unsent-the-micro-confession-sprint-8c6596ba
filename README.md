One unsent micro-confession, in exactly two parts — a `To:` line and the line itself, written as typed and never sent:

> To: Mom
> I learned to make your soup the week you went into hospital, and I've made it every Sunday since, but I still can't tell you I was practicing for the day you won't be here to make it.

191 characters in total; the message line is 183 characters. No real names, no explanation after it.

## Run it

```sh
python3 main.py
```

Writes the confession to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
